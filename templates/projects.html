ENGINEERING

Engineering Decisions

01

PostgreSQL for Persistent Messaging

Message history requires durable storage that survives application restarts. PostgreSQL provides persistent and queryable message data.

02

Redis for Real-Time Presence

Online status changes frequently and requires fast access. Redis separates temporary presence state from persistent message storage.

03

Docker for Reproducible Infrastructure

Docker Compose orchestrates the application, PostgreSQL, and Redis services in a consistent development environment.

04

Automated CI Testing

GitHub Actions runs pytest automatically to detect regressions whenever changes are pushed to the repository.
